## Implemented contract and limits
Price API remains GET /api/v1/price-series/{symbol}; response model schema_version is now 3. Default range 1h; allowlisted range query 5m/15m/1h/4h/24h. format=csv or format=json produces attachment; absent format returns JSON for polling. Invalid symbol/range/format returns 400/no-store; source failures return 503; absent retained symbol returns INSUFFICIENT_HISTORY with empty points, no fixture fallback.
One read-only SQLite transaction resolves the latest valid positive finite sample at/before read time, then selects the requested historical window. The read returns at most 10000 rows plus an overflow sentinel; normalization discards invalid/future/duplicate samples, orders event time, emits at most 1200 actual samples including endpoints. No interpolated sample is created. Prefix gap evidence ensures downsampling neither falsely breaks a continuous sparse render nor bridges actual >60s gaps. A sampled series is not an exhaustive raw-data export. Oversized windows visibly flag truncated; physical query cost still depends on the existing symbol/time index and stored data, no arbitrary latency guarantee claimed.
Bounds, anchor/read times, sample counts/budgets, gap_count, truncated/downsampled and coverage PARTIAL_OR_UNVERIFIED are explicit. AVAILABLE means >=3 observed samples, never complete coverage. CSV includes source/schema/symbol/range/anchor/read/requested/observed dates, raw/display counts, flags, gap count and timestamp_ms/UTC/price_USDT/gap_before columns. Empty CSV retains metadata in a row with blank sample columns. JSON uses identical model as chart API. Attachments are independent fresh reads with the same parameters; they are NOT frozen to a previous chart response if another writer advances the DB. Each response records its own read/observation bounds.
Legacy pure v1 current-window and v2 historical-1h normalizers remain for their own tests; production route uses v3. Movers sparklines consume default 1h using gap-aware path rendering. No historical fetch/backfill or collector start.
